# Загрузчик медиафайлов

Приложение для скачивания аудио и видео файлов с различных сайтов с графическим интерфейсом пользователя.


## ✨ Возможности

- 📥 Скачивание видео в формате MP4
- 🎵 Скачивание аудио в формате MP3
- 🌐 Поддержка множества платформ (YouTube, Vimeo, SoundCloud, TikTok и др.)
- 🖥️ Удобный графический интерфейс пользователя на Tkinter
- 📊 Отображение прогресса загрузки с деталями
- 💾 Быстрый выбор директории сохранения
- 📂 История используемых директорий
- ⌨️ Горячие клавиши и контекстное меню для быстрого редактирования URL
- ⚠️ Предупреждения о неверных директориях

## 📋 Требования

### Базовые зависимости
- **Python 3.8** или выше
- **tkinter** (входит в стандартную библиотеку Python)

### Внешние библиотеки
- `yt-dlp` — для скачивания контента (устанавливается через `pip`)

### Системные зависимости
- **FFmpeg** — необходим для конвертации видео в MP3
  - Windows: [скачать с официального сайта](https://ffmpeg.org/download.html)
  - macOS: `brew install ffmpeg`
  - Linux: `sudo apt install ffmpeg` (Ubuntu/Debian) или аналогичная команда для вашего дистрибутива

## 🚀 Использование

### Вариант 1: Через терминал

**Прямой запуск:**
```bash
python main.py
```

### Вариант 2: Использование исполняемых файлов

После сборки PyInstaller:
- **Windows**: Запустите `run.bat`
- **Linux/macOS**: Запустите `run.sh`

### Работа в приложении

1. **Введите URL** видео в поле ввода (контекстное меню для быстрого редактирования)
2. **Выберите формат**: MP4 (видео) или MP3 (аудио)
3. **Укажите директорию** для сохранения:
   - Кнопка "Обзор..." для выбора директории
   - Из списка истории для быстрого доступа
4. **Нажмите "Загрузить"**
5. **Следите за прогрессом** в статусной панели

## 🐛 Решение проблем

### Если приложение не запускается

**1. Проверка Python:**
```bash
python --version
# Должно показать 3.8 или выше
```

**2. Проверка зависимостей:**
```bash
pip install yt-dlp
```

**3. Проверка FFmpeg (для MP3):**
```bash
ffmpeg -version
```

### Если загрузка не работает

**1. Проверка URL:**
- URL должен быть действующим и публичным
- Проверьте доступность сайта через браузер

**2. Проверка интернета:**
- Убедитесь, что интернет работает
- Попробуйте другой URL для тестирования

**3. Проверка прав доступа:**
- Убедитесь, что у приложения есть права на запись в выбранную директорию

### Если конвертация в MP3 не работает

**1. Установка FFmpeg:**
```bash
# Windows
# Скачайте исполняемый файл FFmpeg и добавьте путь в переменную PATH
# или установите через Chocolatey: choco install ffmpeg

# Linux
sudo apt install ffmpeg

# macOS
brew install ffmpeg
```

**2. Проверка PATH:**
```bash
ffmpeg -version
# Должна вывестить информацию о версии
```

**3. Альтернатива:**
Скачивание в MP4 и конвертация через другие инструменты
